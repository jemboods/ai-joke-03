A tiny program that writes one original joke about AI coding agents to its output file. It keeps a small anthology of one-liners, scores each on surprise, truth, economy and freshness, and writes the winner — deterministically, the same bytes every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
